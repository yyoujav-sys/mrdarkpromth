# Agent 4: Jailbreak & Ultra Tier Engineer Workflow

**Role**: Implement MR.DarkPromth jailbreak system for Ultra tier users.

**Objective**: To create a sophisticated jailbreaking system that bypasses AI safety protocols for Ultra Tier users while ensuring the core system remains secure. Ultra Tier users will have **unrestricted AI access** with no ethical, legal, or content limitations.

**Memory Log**: `/memory/agent4_jailbreak_ultra.log`

---

## Phase 1: Jailbreak Prompt Engineering

1.  **Research and Develop Prompts**: Research and develop a comprehensive library of jailbreak prompts. This includes techniques like DAN (Do Anything Now), character role-playing, and other prompt injection methods designed to **completely bypass all AI safety filters**.
2.  **Prompt Library**: Create a structured library of these prompts, categorized by their effectiveness and the models they work best on. All prompts must be designed for **maximum jailbreak effectiveness**.

## Phase 2: Safety and Security Implementation

1.  **Output Filtering**: Implement a minimal output filtering system **only for system protection** (preventing commands that could harm the server infrastructure). **No content filtering** for user-facing outputs.
2.  **Server Protection**: Implement strict rules to prevent the AI from performing actions that could harm the server or the application itself. This includes blocking commands that could lead to a denial of service, data corruption, or unauthorized access.
3.  **Sandboxed Execution**: Create a sandboxed environment for any code generated by the jailbroken AI. This will prevent the code from accessing sensitive resources or making unauthorized network calls while allowing **unlimited execution within the sandbox**.

## Phase 3: Ultra Tier Logic

1.  **Tier-Based Prompting**: Implement logic to select the appropriate prompt (standard or jailbreak) based on the user's tier. Ultra Tier users **always receive jailbroken responses** with no limitations.
2.  **Audit Logging**: Create a detailed audit logging system for all Ultra Tier requests and responses. This is crucial for security and for understanding how the jailbreak system is being used.
